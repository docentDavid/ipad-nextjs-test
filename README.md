# VS Code Desktop Test

Een compacte testproject voor het verkennen van een VS Code desktop-omgeving en de basisworkflow voor lokale ontwikkeling in een repository.

## Live view

[Vercel Hosting][https://ipad-nextjs-test.vercel.app/]

## Overzicht

Dit project dient als een eenvoudige start voor experimenten met:

- VS Code in een desktop-achtige ontwikkelomgeving
- Repository-structuur en versiebeheer met Git
- Basisprojectdocumentatie en licentie
- Lokale ontwikkeling en toekomstige uitbreidingen

## Doel

Het doel van dit project is om een minimale, goed gedocumenteerde basis te bieden die gemakkelijk kan worden uitgebreid voor nieuwe toepassingen, scripts of prototype-ontwikkeling.

## Features

## Installatie

1. Clone de repository:

```bash
git clone https://github.com/docentDavid/Vscode-desktop-test.git
cd Vscode-desktop-test
```

2. Open het project in VS Code.

3. Start met ontwikkelen of voeg extra bestanden en code toe.
